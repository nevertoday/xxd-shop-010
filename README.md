## 它解决什么

详情页里需要很多“小模块”：口味标签、卖点卡、规格卡。它们要干净、好扫读、能直接嵌进白底页面，又不能平到没人看。

**Shop 010** 的答案是一张白底上的标签卡：商品嵌在卡里，**最诱人的那一部分越过标签边缘**，产生立体感和食欲；文字三层就够：顶部一句引导语，中部醒目的主标题，下部英文或小卖点。

它不是海报，是信息模块。

## 你的文案会怎么处理

| 你给了什么 | 怎么处理 |
|---|---|
| 没给文案 | 模型按“这是什么、有什么特点、为什么值得选”写短文案 |
| 给了一段文案 | 当作**文案方案**：分析主次，提炼成主标题、副标题、卖点，可以压缩整理，但不改意思、不加事实 |
| 说了“一字不改” | 逐字使用 |

这和其他编号不一样：原稿本来就要求优化用户的文案方案，所以这里默认是方案模式。生成前会用一句话告诉你本次用的是哪种。

## 你需要准备

- **商品图：** 推荐，越界部分的形态会照着图来。
- **商品信息：** 品类、口味、核心卖点、消费场景。
- **事实：** 糖度、产地、等级、规格，用 `--facts` 给。

## 快速判断

| 你关心的问题 | 回答 |
|---|---|
| **你会得到什么** | 一张可以直接嵌进详情页的白底产品标签卡 |
| **一眼可辨的特点** | 纯白背景 · 完整的标签轮廓 · 商品跃出边缘 · 三层文案 · 至多一枚小圆标 |
| **它不会做什么** | 不做成整张海报、不加场景、不堆卖点、不让越界生硬 |

## 开始使用

```bash
git clone https://github.com/nevertoday/xxd-shop-010.git
ln -s "$(pwd)/xxd-shop-010" ~/.claude/skills/xxd-shop-010
```

```text
# 没有文案：模型来写
/xxd-shop-010 ./黄桃罐头.png --product "黄桃罐头" --size 1:1 --text prompt --locale zh-CN

# 有一段文案：按方案提炼层级（默认）
/xxd-shop-010 ./西瓜.png --product "西瓜" --copy "夏天第一口就该是它 沙瓤多汁 皮薄 冰镇更好吃 Summer Watermelon" --facts "单果 5–6 斤" --locale zh-CN

# 文案一字不改
/xxd-shop-010 ./燕麦奶.png --text exact --copy "每一口都是燕麦香" --locale zh-CN
```

常用参数：`--product` · `--copy`（默认按方案处理） · `--text prompt / plan / exact` · `--facts` · `--size` · `--locale`。完整参数见[家族运行合同](references/shop-runtime.md)。
